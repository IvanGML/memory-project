## Why

The project was scaffolded from `npm create vite` with the entire app — every section, every primitive, every type, the data fetch — living in a single 1217-line `src/App.tsx`. There were no working rules, no commit convention, no separation between the data layer and the UI, and no developer journal. Three foundational changes had to land before normal feature work could begin: a structural refactor, a data layer, and the discipline rules + tooling to keep the project honest as it grows.

This entry exists so that future readers scrolling the journal top-to-bottom have a starting point. It is **retroactive** — written after the fact — and is sealed immediately because re-litigating the foundation is out of scope.

## What we built

Five things landed in a single session before the journal was created:

1. **Architecture refactor.** `src/App.tsx` (1217 lines) split into a `QueryClientProvider` shell + `pages/HomePage.tsx` + 7 `sections/*` files + 3 `components/ui/*` primitives + 3 domain components under `components/{memory,gallery}/` + supporting `hooks/`, `lib/`, `types/`, and `content/` folders. Inline styles + CSS variables preserved verbatim.
2. **Data layer.** `@tanstack/react-query` introduced. `src/content/queryClient.ts` and `src/content/useContent.ts` replace the inline `useEffect + fetch + useState` from old `App.tsx`. `staleTime: Infinity`, `refetchOnWindowFocus: false`. The seam where local state meets the (currently static) API.
3. **Husky + commitlint + lint-staged.** `pre-commit` runs `lint-staged` (eslint --fix on staged `*.{ts,tsx}`); `commit-msg` runs commitlint. `commitlint.config.js` enforces a granular `scope-enum` (19 scopes covering sections, layers, and cross-cutting areas) plus `subject-case: never sentence/start/pascal/upper` (allows mid-sentence code identifiers like `useContent`).
4. **CLAUDE.md expansion.** From a thin starter doc to ~150 lines covering Project intent, Architecture, Styling, Conventions, Commit Convention, Environment Configuration, UI Libraries guardrail, Working Rules (Mandatory Interaction · Problem-Solving · Post-Implementation Review pipeline · drift-check · Confidence-always), and explicit out-of-scope.
5. **`commit` skill rewritten.** Carried over from the user's Angular project; rewritten to memory-project's type/scope lists, file-path → scope table, and never-stage list. Reference to `CBY/commitlint.config.js` replaced with the repo-root config.

## Architecture impact

New top-level `src/` folders: `pages`, `sections`, `components/ui`, `components/memory`, `components/gallery`, `content`, `hooks`, `lib`, `types`, `assets`. New runtime dep: `@tanstack/react-query`. New devDeps: `husky`, `@commitlint/cli`, `@commitlint/config-conventional`, `lint-staged`. New repo-root files: `commitlint.config.js`, `.husky/pre-commit`, `.husky/commit-msg`. Existing `index.css` unchanged — class names preserved on the moved components so the hover/animation layer keeps working.

CLAUDE.md sections established in this period: `## Commit Convention`, `## Environment Configuration`, `## UI Libraries`, `## Working Rules`. These are referenced by every subsequent plan.

## Tradeoffs

- **TanStack Query for one static JSON.** Bundle cost (~40 KB gzipped via dependency tree) accepted as down-payment on future API readiness — Frontend Spec §15 lists admin / user accounts / private content as planned extensions, so the second endpoint comes free.
- **Granular commit scopes (19) over flat (6–7).** Higher day-one maintenance cost (every new area requires a deliberate `chore(config)` commit to extend the enum) accepted in exchange for at-a-glance area signal in `git log` once the project grows past one developer.
- **No state manager.** State inventory showed nothing crosses sibling boundaries today. Zustand/Redux/Jotai/MobX deferred until a concrete cross-tree need (theme switcher, admin edit-mode, auth) appears.
- **No router.** Frontend Spec §3 forbids it for MVP; routing decision deferred until admin lands.
- **No UI library.** Public side intentionally hand-rolled per Design Foundation §10. When admin lands, UI lib will be scoped to `pages/admin/**` only.
- **No tests.** Out of scope per the MVP specs; not adopted now to avoid premature test framework lock-in.

## Known limitations / follow-ups

- No admin route exists yet; `pages/admin/**` and `components/admin/**` are guardrails-only.
- `FilmSection` `playing` flag only swaps caption text — there is no real video player.
- `prettier` not configured in `lint-staged` — only eslint runs on staged TS/TSX files.
- No CI yet — Husky hooks are the only enforcement.
- Theme switcher (`data-theme="dark"`) planned in Design Foundation §11 but not wired.
- No i18n switcher (Russian-only single locale).
